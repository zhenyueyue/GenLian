# SCREEN_SPEC.md — 逐页界面结构与状态规格

> **范围说明**：`WarmAppShell`（及其 7 个核心界面状态）为正式 App 需要 1:1 实现的页面体系；桌面端外层控制栏（`src/App.tsx`）与并排对比工作台（`src/components/WarmPerformanceWorkspace.tsx`）仅为设计原型评估工具，**不纳入原生 iOS App 范围**。

---

## 页面导航关系总览

```
[今日首页 WarmTodayView] <──(底部 Dock: 今日 / 档案)──> [训练档案 WarmHistoryView]
   │                                                          │
   ├─ 点击「配重设定 / 配重与休息」 ──> 弹出 [配重与休息设定抽屉]     └─ 点击任意历史卡或月历打卡日
   │                                                                 │
   ├─ 点击任意动作列表项 ──> [动作详情 WarmExerciseDetailView]          v
   │                              │                            [单次训练详情]
   │                              └─ 点击「进入全屏跟练」 ──┐     (返回顶部「档案」)
   │                                                    v
   └─ 点击「开始今日训练 / Dock 开练」 ──────────> [训练执行 WarmPlayerView]
                                                   │
                     prepare → active ⇄ setComplete → rest → nextTransition
                                                   │
                                           (完成全部 / 提前退出)
                                                   v
                                            [训练完成 Summary]
                                                   │
                                       点击「收入个人训练档案」
                                                   └──> 自动跳至 [训练档案] 并高亮最新记录
```

## 1. 今日首页 (`WarmTodayView.tsx`)

### 1.1 页面结构（自上而下）
1. **顶部连续吸顶栏**（`absolute top-0 z-20`）：
   - 左侧：品牌名 `跟练`（`18px SemiBold`）+ 状态副标题（未吸顶：`第 9 周 · 居家哑铃` [Mock]；`scrollY > 180` 吸顶后：课程主标题）。
   - 右侧：未吸顶显示 `配重设定` 玻璃按钮（`.warm-lg-control`）；吸顶后（`.warm-lg-header-blur`）弹性切换为实色橙 `开始` 小胶囊按钮。
2. **全幅晨光 Hero**（高度：`SE 425px` / `Standard 500px` / `ProMax 540px`）：
   - 随滚动产生 `0.26x` 视差、最大 `1.07x` 缩放与渐隐。
   - 底部叠字锁组：Kicker（如 `力量 A · 全身均衡循环`）、大标题（`31px`，SE `26px`）、等宽元数据行（时长范围 · 轮数 · 当前单只片重摘要）。
3. **地平线主行动区**（`#F9F7F3`）：
   - **常态**：主按钮（实色橙 `开始今日训练`）+ 次按钮（`GlassButton` `配重与休息`）；下方显示课程意图语（`intentLine`）与可点击的快速休息时长锚点（`歇 90s`）。
   - **顺延态 (`postponedNote === true`)**：收起常规开始按钮，显示 `GlassPanel(variant="chip")` 卡片「今日顺延 · 留出恢复余量 / 已暂缓『…』」，提供实色橙 `恢复今日训练` 与玻璃次按钮 `改做恢复日`（直切至第 4 门课）。
4. **今日动作顺序列表**：
   - 第 1 个动作（Lead）：`16:9` 宽图卡（底部深渐变叠层显示 `01 · 肌群` 与 `目标次数 · 节奏`），下方展示动作名、目标肌群、当前片重及右箭头。
   - 第 2..N 个动作：左 `108px 4:3` 缩略图（左下角角标 `02`..`04`）+ 右侧名称、目标次数（橙色数字）、目标肌群、片重/节奏/单侧标记（`左右各半`）。
   - 底部安全警告条：`AlertCircle` + `USER_CONTEXT.safetyDisclaimer`（塑料杆承重待确认警示）。
5. **更换训练内容网格**：2 列课程卡展示全部 4 套方案（`力量 A`、`力量 B`、`有氧`、`恢复日`），选中卡描边 `1.5px #D44E24`。
6. **底部悬浮导航 (`GlassDock`)**：固定于安全区上方，含「今日 / 开练 / 档案」三入口。

### 1.2 课程状态差异
- **力量 A (`strength-a`)**：3 轮 × 4 动作，默认歇 90s / 轮间 120s，默认 `p-4.0`。
- **力量 B (`strength-b`)**：3 轮 × 4 动作，默认歇 90s / 轮间 120s，默认 `p-3.0`。
- **有氧 (`cardio`)**：3 轮 × 4 动作，默认歇 30s / 轮间 45s，默认 `p-2.5`。
- **恢复日 (`recovery`)**：2 轮 × 2 动作（胸椎旋转+死虫式），纯徒手 `defaultPlateId = null`，默认歇 20s / 轮间 30s。

### 1.3 配重与休息设定抽屉 (`showSetupSheet`)
- 遮罩：`bg-black/40 backdrop-blur-sm`，底部弹出 `.warm-lg-sheet`（最大高度 `84%`）。
- 区域 A（哑铃装片组合）：若当前课程需用哑铃，显示当前配重卡（`.warm-lg-chip`，含装片明细、库存消耗与 `cautionNote` 警示）+ 10 档 2 列装片预设矩阵（选中使用 `#191D22` 石墨底）；若为恢复日，显示「当前为纯徒手恢复日，无需装配哑铃」。
- 区域 B（组间休息时长）：4 档快速选择 `30s / 60s / 90s / 120s`（轮间自动 `+30s`；选中使用 `#D44E24` 橙底）+ 「倒计时结束自动进入下一动作（自动推进 / 手动确认）」玻璃切换条。
- 底部动作：`今日顺延一天`（玻璃芯片）+ `保存并开练`（实色橙按钮）。

## 2. 训练 / 动作详情 (`WarmExerciseDetailView.tsx`)

- **层级**：`absolute inset-0 z-40` 全屏覆盖（从 `today` 打开，隐藏底部 3-Tab Dock）。
- **上半舞台**（`54%` 高，SE 为 `48%`）：共享转场 `layoutId="warm-perf-stage-media"` 展示动作图（支持 `detailContain` 完整呈现人体与器械），底部叠加 `detailHeaderOverlay` 渐变并锚定分类/肌群/单侧副标题与动作大标题。
  - 顶部导航行：`GlassButton`（`‹ 今日`）+ `GlassPanel`（`动作 01 / 04`）+ 左右切动作 `GlassIconButton`（首尾自动 `disabled:opacity-30`）。
- **下半滚动参数区**：
  - 摘要条：`目标 X 次/秒 · 配重标签 · 节奏 X-X-X`。
  - 发力与节奏要求：若节奏匹配 `^\d+-\d+-\d+$`，拆为 3 栏 `GlassPanel(variant="chip")` 展示「离心下放 / 底部停顿 / 发力推拉」秒数；否则展示自然文字节奏说明（如「深慢控制，保持核心张力与平稳呼吸」）。下方展示 `voiceCue` 语音引导正文。
  - 键值明细：`重点部位`（`targetMuscle`）与 `就位提示`（`nextPrepCue`）。
- **底部 Dock**：容器固定在底部安全区之上（非浮于滚动内容内遮挡文字），内嵌全宽实色橙按钮 `进入全屏跟练`。

## 3. 训练执行 (`WarmPlayerView.tsx`)

覆盖 `prepare`、`active`、`setComplete`、`nextTransition` 四个活跃阶段，外加 `isPaused` 与 `showExitConfirm` 覆盖层。

### 3.1 通用舞台与顶部浮层
- **Layer 0 全屏舞台**：优先渲染循环 `<video>`（仅当提供真实 `videoUrl` 或开启原型「注入测试视频」且加载成功时）；否则渲染垂直/匹配静态姿态图；无图时显示「暂无该动作实拍视频」暖白占位卡片。
- **Layer 2 顶部节拍与导航**（`z-20`）：
  - 顶部 `N` 段进度细轨（`2.5px` 高）：已完成 `#D44E24`，当前段 `#191D22`（降亮期 `#F9F7F3`），未完成低透明轨道。
  - 左 `GlassButton(退出)` + 中 `GlassPanel` 状态胶囊（`第 R/T 轮 · 动作 i/N · MM:SS`）+ 右 `GlassIconButton`（语音开关，关闭时降透明度 `0.55`）。
  - 第二行提示条：左侧副提示胶囊（`示范循环中` 或 `实景姿态参考 · 按自身节奏发力`），若处于原型跳转预览态右侧额外显示 `预览态` 标签。

### 3.2 四大执行子阶段

1. **`prepare`（4 秒开练准备）**：
   - 背景进入 76% 亮度降亮态，顶部/中间文字转浅色，顶部按钮切换为深烟熏 `.warm-lg-dim-control`。
   - 中央显示 `第 R 轮 · 准备就位`、动作名、`88px`（SE `74px`）倒计时（≤3s 转暖橙 `#FF9E7D`）、`nextPrepCue`、配重与目标次数。
   - 底部单一高对比提亮玻璃按钮（`GlassButton elevated`）：`我已就位，立即开始`。

2. **`active`（动作跟练中）**：
   - 画面恢复正常亮度（`photoFilterClass`），顶部控件使用亮底玻璃 `.warm-lg-control`。
   - 底部左区：若动作 `isUnilateral === true`，显示单侧分段胶囊（`左侧 进行中/✓` · `右侧`）；下方显示 `肌群 · 配重 · 节奏`、动作名、`voiceCue`（静音时切换显示 `targetMuscle`）。若当前播放真实视频，显示 `重播` 与 `已静音/原声` 两个小型玻璃按钮。
   - 底部右缘：**竖向玻璃次数步进器**（`GlassPanel variant="control"`）：顶部 `+`（≥44px 触控区）、中央实时显示 `repDraft`（点击可一键复位至 `targetReps`；被微调后数字变橙并显示回退小箭头）、底部 `−`（下限为 1）。
   - 底部拇指主操作区：
     - **实色品牌橙主按钮**：文案动态反馈当前推进语义（`完成左侧 (12 次) · 切右侧` / `完成本动作 · 记 12 次` / `完成收官组 · 记 12 次`）。
     - **光学辅控 3 格条**（`GlassPanel variant="control"`）：`上一动作`（首轮首动作禁用） / `暂停 | 继续` / `跳过动作`。

3. **`setComplete`（完成一组后 4 秒确认窗）**：
   - 背景温和降亮（74%），整屏内边缘高亮 `2px #D44E24` 提示刚记入 1 组。
   - 底部悬浮 **`.warm-lg-rest-card` 面板**：
     - 标题行：`本组已实录 · 动作名` + 右侧倒计时（`4s 后进休息` / 触碰任意调节后显示 `已暂停自动倒数`）。
     - 实做次数微调行：`−` / `actualReps` / `+`（点击自动暂停自动跳转）。
     - 主观感受 3 选 1 胶囊组：`轻松` / `正好` / `吃力`（选中石墨底，未选 `.warm-lg-chip`）。
     - 实色橙主按钮：`立即进入休息 (Xs)` 或 `进入组间休息`。
     - *边界保护*：若通过原型调试直接跳入 `setComplete` 且尚无 `loggedSets`，显示「尚未记录完成组，不伪造实录」及「返回动作跟练」。

4. **`nextTransition`（2 秒动作切换过渡）**：
   - 背景降亮 76%，中央显示跨轮提示或 `切换动作 · 02/04`、新动作名、配重/单侧先左手提示、`nextPrepCue` 及 `54px` 倒计时 `2 -> 1`。
   - 底部高对比玻璃按钮：`直接开始本动作（X 次）`。

### 3.3 覆盖遮罩
- **`isPaused`（主动暂停遮罩）**：`GlassOverlay variant="pause"` 全屏淡暖白磨砂（`rgba(249,247,243,0.92)` + `blur(12px)`），显示 `主动暂停 · 已暂停 Xs`、`暂不记录完成，也不跳过动作`、当前轮次与动作名、实色橙 `继续跟练`、玻璃次按钮 `提前结束训练（已录 X 组）`。
- **`showExitConfirm`（退出确认抽屉）**：`GlassOverlay variant="scrim"` + 底部 `.warm-lg-sheet` 抽屉，依据 `loggedSets.length === 0` 或 `> 0` 准确提示退出后的记录归因；提供石墨实色 `继续当前训练` 与玻璃 `提前结束并查看总结`。

## 4. 组间休息 (`WarmPlayerView.tsx` 中的 `rest` 阶段)

- **视觉降压**：舞台视频暂停、画面在 `500ms` 内降至 `brightness(0.72) saturate(0.82)` 并叠加 `32%` 石板暮纱，人物与房间环境仍保持呼吸可见。
- **顶部栏**：全部切换为深烟熏 `.warm-lg-dim-control` 搭配 `#F9F7F3` 文字。
- **中央焦点**：
  - 上下文副标（自动区分力量「组间/轮间恢复」、有氧「有氧训练间歇/间歇恢复」、恢复日「舒展间歇/过渡」）。
  - 若由原型预览直接进入且 0 完成组，顶部显示提示「未记录完成组（休息预览态 · 不写入档案）」。
  - `90px`（SE `74px`）`Outfit` 超大倒计时（最后 3 秒变 `#FF9E7D`；若开启手动确认且倒数归零，显示「`就绪`」）。
  - `192px × 2.5px` 细进度条 + `已实休 Xs · 设定 Ys`。
  - **下一动作预告卡（`GlassPanel variant="rest"`）**：`84px` `16:9` 缩略图 + `下一个 · 序号/跨轮` + 动作名 + 目标次数与配重。
- **底部 3 按钮**：两个烟熏玻璃 `-15s` / `+15s` + 提亮暖白玻璃主宽按钮 `提前结束休息`（或手动等待态时为 `开始下一动作`）。

## 5. 训练完成 (`WarmPlayerView.tsx` 中的 `summary` 阶段)

- **3 种终态区分**：
  1. `completed`（完成全部计划动作且无跳过）：橙色标签「今日训练完整完成 / 按计划完成全部轮次」。
  2. `early_exit_partial`（至少完成 1 组后退出，或含跳过动作完成终局）：琥珀标签「提前结束 · 保留部分实录 / 已记下本次完成组，不影响节奏」。
  3. `early_exit_zero`（0 组完成退出）：灰阶化头图 + 灰调标签「提前结束 · 完成 0 组 / 未计入完整课程完成次数」，不伪造容量。
- **内容区**：头图渐隐 + 起止时间与暂停总时长 + 3 列精密统计带（`完成组数` / `累计次数/秒` / `有效时长 MM:SS`）+ 按轮分组的实录明细 + 跳过动作清单（如有）。
- **底部 Dock**：`GlassDock` 包裹全宽实色橙按钮 `收入个人训练档案`。

## 6. 训练档案 (`WarmHistoryView.tsx` 列表与月历)

- **底部光影层**：主画布 `#F9F7F3` 上叠加微弱径向暖晕及首条训练头图的 `8%` 透明度超大模糊底影，让列表中 `.warm-lg-chip` 卡片产生真实的透光层次感。
- **吸顶头部**（`scrollY > 8` 启用 `.warm-lg-header-blur`）：
  - 左上标题：`个人训练志` / `训练档案`。
  - 右上分段开关（`GlassSegmentedControl`）：`记录` / `月历`。
  - 第二行分类筛选（无外框 `GlassSegmentedControl`）：`全部` / `力量` / `有氧` / `恢复`。
- **3 列累计度量带**：`有效训练（含完整完成数）`（剔除 0 组退出）、`累计时长 min`、`实录容量 组`。
- **月历视图**（`viewMode === 'calendar'`）：`GlassPanel(variant="chip")` 展示 7 列网格，完整完成为橙底白字、部分完成为软橙底描边琥珀字、0 组退出为浅石灰底。*(注：当前硬编码展示 2026 年 11 月 30 天)*。
- **记录列表**：
  - 当筛选为 `全部` 且有数据时，首条渲染为 `16:10` 大图焦点卡；若刚从 `summary` 收入（`justArchivedId`），卡外叠加 `2px #D44E24` 边框并显示「刚刚收入档案 · 点击核对逐组明细」。
  - 其余历史条目使用 `.warm-lg-chip` 横排玻璃卡：左侧 `4:3` 缩略图（右下角标注时长，0 组退出灰度处理），右侧显示日期/星期/完成态/`[本次]` 标记、分类与标题、组数比例及主配重。

## 7. 单次训练详情 (`WarmHistoryView.tsx` `selectedRecord` 态)

- **头图区**（`285px`，SE `245px`）：展示对应课程封面图（0 组退出灰阶），上下叠加浅色渐变，左上 `GlassButton`（`‹ 档案`），右上 `GlassPanel` 徽标（`演示样本实录` / `本次训练实录`），左下状态分类、课程标题及日期/起止时刻/暂停秒数。
- **正文区**：
  - 可选训练备注卡（`GlassPanel variant="chip"`）。
  - 3 列度量带：`实录组数/计划总组数`、`累计次数/秒`、`有效时长 MM:SS`。
  - `逐组实录明细`：按轮次分组展示每组动作名（含单侧左/右）、所用配重与实休秒数、实际/目标次数及主观感受（`轻松/正好/吃力`）；0 组记录时显示规则说明卡。
  - 若含跳过动作：底部单列琥珀色标题与 `GlassPanel(variant="chip")` 跳过时间戳列表。
- **底部栏**：此时仍处于 `WarmAppShell` 的非 Player 视图下，底部保留统一的 `GlassDock` 3-Tab 悬浮底栏，用户可直接切回「今日」或快速「开练」。
