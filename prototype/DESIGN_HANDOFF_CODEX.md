## 1. 页面结构与布局比例

APP 包含三大主页面（首页、沉浸训练舞台、总结页），其中沉浸训练舞台按状态呈现 5 种清晰节奏氛围。**禁止将训练页拆回“顶部视频框 + 中间黑色留白 + 底部工具栏”的三段式结构。**

### 1.1 今日训练首页（`today`）
- **整体结构**：纵向三层非重叠结构（`VStack(spacing: 0)`）。
  1. **顶部弹性栏（固定高度区）**：日期/弹性上下文提示 + 右上「更换 / 顺延」入口（`minHeight: 40pt`）；下方横向课程分类选择器（`力量 A` / `力量 B` / `有氧` / `恢复日`）。
  2. **中间可滚动内容区（`ScrollView`, `flex-1`）**：
     - 课程头图卡：圆角 `24pt`，高度 `192pt`（SE `164pt`），底部渐变遮罩上叠加弹性说明、标题与 `预估时长 · 轮数 · 动作数/轮`。
     - 哑铃配重设定区：双行结构化信息卡（单只装片明细 + 库存占用），下方紧邻琥珀色安全免责警示，底部为横向滑动示例片重选择条（`仅空杆` ~ `14.5kg片`）。
     - 休息节奏设定区：头部实时显示 `动作间 Xs · 轮间 Ys`；4 等分网格预设（`30s / 60s / 90s / 120s`）；独立一行切换「倒计时结束后：自动进入下一动作 / 等待手动确认开始」。
     - 单轮循环动作列表：按 `01`–`04` 编号列出动作名、目标肌群与节奏、单臂/素材状态提示、目标次数与当前跟随片重。
  3. **底部独立固定操作栏（非浮层覆盖！）**：放在 `ScrollView` 外部底部的 `shrink-0` 区域，顶部带 `1pt` `#1E2227` 分隔线与 `20pt` 向上渐变过渡唇，确保用户滚到底部时第 4 个动作不会被「开始今日跟练」按钮遮挡。

### 1.2 沉浸训练舞台（`B1.5` 全屏结构：`prepare` / `active` / `setComplete` / `rest` / `nextTransition`）
- **Z 轴图层顺序（`ZStack` 由底向上）**：
  1. **Layer 0 · 100% 全屏媒体层（`.ignoresSafeArea()`）**：`AVPlayer` 竖屏视频（无实拍视频时降级为明确占位视图或已核验的静态参考图），铺满整块屏幕。
  2. **Layer 1 · 双向光学暗角保护层**：
     - 顶部暗角：高度 `144pt`，`LinearGradient(black.opacity(0.82) -> black.opacity(0.38) -> clear)`。
     - 底部暗角：`active` 时占屏高 `44%`（SE `48%`），`rest / setComplete / prepare / nextTransition` 时扩展至 `58%`，由 `#08090B`（100% 不透明）向 `#08090B`（84%）再到透明渐变。
  3. **Layer 2 · 中央焦点舞台层（`active` 时完全留白不遮挡动作主体！）**：
     - `prepare`：居中动作名 + `86pt` 大号启动倒计时 + 准备姿态提示。
     - `rest`：背景进一步压暗去饱和（`brightness 0.16, saturation 0.2`），中央仅保留超大号等宽倒计时（`92pt`，SE `76pt`）作为绝对视觉中心（无硬质圆环），下方配 `2pt` 极细水平进度线与弱对比实休秒数，隔开留白后下方放置「即将开始」紧凑预告卡（最大宽 `324pt`）。
     - `nextTransition`：居中聚焦提示 + `32pt` 新动作大标题 + 配重/目标参数 + 准备要点 + `52pt` 切换倒计时。
  4. **Layer 3 · 顶部安全区轨道与极简排印 HUD**：
     - 4 段等宽进度条（高 `3.5pt`，圆角全满，`spacing: 6pt`）。
     - 三列顶部控制：`[退出]` 玻璃按钮 — `第 X/3 轮 · 动作 Y/4 · MM:SS`（纯文字 + 文字阴影，禁止气泡胶囊包裹） — `[语音开关]` 圆形按钮。
     - 其下 1 行媒体状态说明文字（明确告知视频循环不锁速，或提示当前处于无视频占位态）。
  5. **Layer 4 · 底部悬浮信息与操作区**：
     - `active` 状态：上方左右分栏（左侧 `flex-1` 为单臂切换条 + 肌群/配重/节奏 + `26pt` 动作名 + 1 行要领 + 视频重播/静音微按钮；右侧 `shrink-0` 为宽 `52pt` 竖向拇指次数标尺 `+ / 实数 / −`）；下方为系统化半透明磨砂底坞（总高约 `108pt`，内含 `52pt` 荧光绿主按钮 + 3 等分 `40pt` 辅助控制栏）。

### 1.3 训练总结页（`summary`）
- 顶部状态语义头（区分「完整完成」「提前结束（部分完成）」「提前结束（完成 0 组）」）+ 真实起止时钟 + 累计暂停秒数。
- 3 列核心实录指标（`实录完成组` / `实录总次数或秒` / `有效训练时长`）。
- 逐组实录明细表（含轮次、动作名、左右侧、配重、实际休息秒数、起止时间戳、实做/目标次数与主观难度）。
- 若存在跳过记录，单独展示「跳过动作记录（未计为完成）」列表。
- 底部独立固定「完成并回到今日训练」按钮。

### 2.2 字体体系与层级
- **展示大标题 / 大号计时（Display）**：`Outfit`（iOS 可配 `SF Pro Rounded` Bold/Heavy 或内置 `Outfit` 字体包）
  - 休息中央主倒计时：`92pt`（SE `76pt`）Heavy `monospacedDigit()`，`tracking: -0.03em`（无外围圆环）
  - 准备倒计时：`86pt` Heavy `monospacedDigit()`
  - 下一动作过渡倒计时：`52pt` Heavy `monospacedDigit()`
  - 下一动作名称：`32pt` Heavy
  - 动作进行中标题：`26pt`（SE `23pt`）Heavy
  - 首页/总结主标题：`25pt–28pt` Bold/Heavy
- **正文字体**：系统默认 `PingFang SC` / `SF Pro Text`（12pt–16pt）
- **数据与计时器（Tabular Numerals）**：`JetBrains Mono` 或 `SF Mono` + 强制开启 `.monospacedDigit()`（防止倒计时每秒跳动导致水平抖动）。

### 2.3 间距与圆角规范（遵循 $r_{\text{inner}} = r_{\text{outer}} - \text{padding}$）
- **页面水平外边距**：首页 `20pt`，训练舞台 `16pt`。
- **同心圆角规则**：
  - 磨砂底坞外容器：`cornerRadius = 24pt`，`padding = 8pt` → 内部荧光绿主按钮 `cornerRadius = 16pt`，次级控制格 `cornerRadius = 12pt`。
  - 右缘次数标尺外容器：`cornerRadius = 20pt`，`padding = 6pt` → 内部 `+/−` 按钮 `cornerRadius = 14pt`。
  - 休息下个动作预告卡：`cornerRadius = 16pt`，`padding = 10pt` → 左侧缩略图 `48×48pt` `cornerRadius = 12pt`。
  - 首页头图卡：`cornerRadius = 24pt`；底部抽屉顶部：`cornerRadius = 24pt`。

## 3. iOS 安全区域适配（Safe Area）

| 区域 | iPhone 15 Pro Max / 15 Pro（灵动岛） | iPhone SE（无刘海小屏） | 实现规则 |
| :--- | :--- | :--- | :--- |

## 4. 组件及其不同交互状态

### 4.1 顶部段式进度条（`RoundProgressRailway`）
- 按 `plan.exercises.count` 等分（力量训练为 4 段，恢复日为 2 段）。
- **已完成段**：`#C8F542` 100%。
- **当前段**：`#FFFFFF` 100%。
- **未开始段**：`#FFFFFF` @ `20%`。

### 4.2 右缘竖向拇指次数标尺（`VerticalRepRail`）
- **布局**：垂直排列 `[+]`、`[当前数字 + 单位/还原]`、`[−]`。
- **默认态（`repDraft == targetReps`）**：数字为 `#FFFFFF`，底部显示单位（`次` / `秒`）。
- **已修改态（`repDraft != targetReps`）**：数字变为 `#C8F542`，下方显示回退图标 + 原目标次数；点击中间数字区一键重置回 `targetReps`。
- **单手交互**：`+` 在上方、`−` 在下方，契合单手握持时右手拇指自然上下点按轨迹；`−` 下限锁定为 `1`。

### 4.3 底部系统化磨砂控制坞（`StageActionDock`）
- **进行中（`active`）**：
  - 主按钮（`#C8F542`）：双侧动作显示 `完成本动作 · 记 X 次`；单臂左侧显示 `完成左侧 (X 次) · 切右侧`；最后一轮最后一个动作显示 `完成收官组 · 记 X 次`。
  - 辅助三连栏：`上一动作`（无上一动作时 `opacity: 0.3` 禁用）、`暂停 / 继续`、`跳过动作`。
- **完成一组（`setComplete`）**：
  - 舞台内边框亮起 `2pt` `#C8F542` @ `70%` 边缘光环。
  - 底坞平滑展开为确认面板：显示 `本组已实录 · 4s 后自动进休息`、大号 `− / +` 实录修正键、三段主观难度选择器（`轻松 / 正好 / 吃力`，选中态白底黑字）、以及 `立即进入休息（Xs）`。
  - **重要逻辑**：一旦用户点按 `− / +` 或任意难度标签，`autoAdvancePaused` 置为 `true`，暂停 4 秒自动跳转倒计时，避免操作到一半被强行切走。
- **组间休息（`rest`）**：
  - 底坞收敛为 1 行 3 键：`[-15s]`、`[+15s]`、`[提前结束休息 / 开始下一动作]`（倒计时归零且设定为手动确认时，主按钮文案切换为 `开始下一动作`）。

### 4.4 单臂左右侧切换条（仅 `isUnilateral == true` 时显示）
- 左侧开始时：`左侧 进行中` 高亮，`右侧` 暗态；完成左侧记录后自动切换为 `左侧 ✓` + `右侧` 高亮，**且保持在同一轮次、同一动作上，绝不提前进入休息或下一动作**。

### 4.5 暂停遮罩（`isPaused == true`）与退出确认抽屉
- **暂停遮罩**：`#08090B` @ `90%` + 背景模糊，同步暂停背景示范视频与训练有效计时，单独累加 `pausedSeconds`。提供 `继续跟练` 与 `提前结束训练（已录 N 组）`。
- **退出抽屉**：明确告知用户当前实录组数为 0 时将记为「提前结束（完成 0 组）」，大于 0 时记为「提前结束（部分完成）」。

## 5. 页面切换与动画规范

| 触发场景 | 视觉过渡与动画参数 | 注意事项 |
| :--- | :--- | :--- |
| **`active` → `setComplete`** | 底坞向上淡入滑出（`opacity 0→1`, `y +10→0`, `180ms` easeOut），背景图亮度 `1.0 → 0.34`，屏幕内框亮起 `#C8F542` | 不改变视频动作索引 |
| **`setComplete` → `rest`** | 背景图亮度 `0.34 → 0.16`，饱和度降低 `80%`（`saturation(0.2)`），略微放大 `1.03x`；中央超大号倒计时与 `2pt` 细进度线以 `opacity + y(+6→0)` `220ms` 淡入 | 每 1s 平滑推进 `2pt` 细进度线（`linear(duration: 0.5)`），最后 3 秒数字与细线转 `#C8F542` |
| **`rest` → `nextTransition`** | 数据指针切换至下一动作（或下一轮动作 1），背景图恢复彩色并切为新动作画面（亮度 `0.52`），居中展示新动作标题与要点 `2s` 后自动进 `active` | 必须先切数据再入过渡，杜绝“回到动作 1”的状态残留 |
| **触控按压反馈** | 主/次按钮按压 `scaleEffect(0.985)` 或 `0.95`，时长 `100ms–150ms` | 配合 `UIImpactFeedbackGenerator`（`.medium` 用于完成一组，`.light` 用于加减次数） |
| **低动态模式** | 遵循系统 `accessibilityReduceMotion`，关闭缩放位移，仅保留 `opacity` 淡入淡出 | 保证运动时眩晕敏感用户可用 |

## 6. 训练跟练视频的布局与播放规则

> **当前原型现状说明（务必知悉）**：
> 1. 截至本交付节点，项目素材库 `/src/assets/images/` 中**仅有静态摄影图（`.jpg`），尚未配备真人实拍的动态动作视频**。
> 2. 原型中已完整实现基于 HTML5 `<video>` 的真实播放器能力（循环、动作切换重载、静音切换、重播、暂停同步），并在 `public/videos/` 放置了 2 段轻量 H.264 `9:16` 测试流（`test-demo-1.mp4`、`test-demo-2.mp4`），仅在右侧调试栏点击「注入测试视频流」时启用。
> 3. **真实现状下所有未接入真实视频的动作均展示明确占位态**，且在拥有核验匹配的静态姿态参考图时明确标注「静态姿态参考 · 暂无动态示范视频」，绝不使用不匹配的图片冒充动作演示。

### SwiftUI 原生播放规范（`AVPlayer` / `AVPlayerLooper`）
1. **视频比例与裁切**：优先使用 `9:16` 竖屏实拍素材（人物置于画面中上部 `2/3` 区域，下 `1/3` 保留干净暗色地面以避让底部文字与控制坞），使用 `.aspectRatio(contentMode: .fill)` 全屏铺满。
2. **循环与不锁速原则**：
   - 使用 `AVQueuePlayer` + `AVPlayerLooper` 在 `prepare`、`active`、`nextTransition` 状态无缝循环播放。
   - **力量训练视频仅作动作示范，不绑定用户实际次数完成节奏**：用户按自身发力速度完成动作并手动点击「完成本动作」，视频循环周期不触发自动记组。
3. **动作切换**：当 `currentExercise.id` 变化时，立即替换 `AVPlayerItem` 并将播放进度重置为 `.zero`。
4. **暂停与休息同步**：
   - `isPaused == true` 或进入 `rest` 阶段时立即 `player.pause()` 降低功耗与视觉干扰；恢复 `active` 时调用 `player.play()`。
5. **静音与重播控制**：
   - **视频音轨默认静音**（`player.isMuted = true`），且**视频静音状态与语音教练播报开关相互独立**，避免示范视频背景音打断语音口令。
   - 提供独立「重播视频」按钮，点击后 `player.seek(to: .zero)` 并从头播放。
6. **资源缺失占位态**：当动作的 `videoAssetName == nil` 或本地加载失败时，进入明确的占位视图：若存在已核验匹配的静态参考图则显示该图并明确标明「静态姿态参考 · 暂无动态视频」；若图与视频均缺失，则展示深色中性占位舞台与「暂无示范视频素材」，引导用户阅读动作要领。

## 7. 音效与语音反馈规范

- **音频会话配置（iOS 关键）**：
  - 使用 `AVAudioSession.sharedInstance().setCategory(.playback, mode: .spokenAudio, options: [.mixWithOthers, .duckOthers])`。
  - **必须支持后台混音与压低背景音乐（Ducking）**：用户往往边听 Apple Music / Spotify 边跟练，语音播报时短暂压低背景音乐音量，播报结束后恢复，**绝不能打断或暂停用户自己的音乐**。
- **提示音与语音触发时机**（受右上角 `soundEnabled` 开关控制）：
  - **准备/休息倒数 3、2、1**：轻短正弦/系统提示音（类似 Prototype `540Hz / 70ms` 或轻触觉 `.rigid`），不喧宾夺主。
  - **准备结束开练**：清脆上扬提示音（`880Hz`）+ `AVSpeechSynthesizer` 中文语音播报「开始，{动作名称}」。
  - **完成左侧单臂动作**：轻提示音（`720Hz`）+ 播报「左侧完成，请换右侧」。
  - **休息结束**：上扬提示音 + 播报「休息结束，准备{下一动作名称}」。
  - **全部轮次完成**：播报「全部轮次已完成，辛苦了」。

## 8. 可访问性与触控尺寸

- **最小触控热区**：所有按钮（包括右缘 `+ / −`、顶部「退出」「语音」、底栏「上一/暂停/跳过」、完成一组微调键）交互热区 **必须 $\ge 44 \times 44\text{pt}$**（如视觉尺寸为 `40×40pt` 或 `32pt` 高度，需通过 `.contentShape(Rectangle())` 与外扩 padding 补足 `44pt` 热区）。
- **主操作按钮尺寸**：`开始今日跟练`、`完成本动作`、`提前结束休息` 高度 $\ge 52\text{pt}$，适配出汗、单手盲操场景。
- **对比度与色盲友好**：
  - 主按钮深字配荧光绿（`#111315` on `#C8F542`）对比度远超 `10:1`；暗角叠加文字在视频高光处需加投影或暗角 scrim 确保 $\ge 4.5:1$。
  - 严禁仅靠颜色区分状态：例如配重超限警示同时搭配 `AlertCircle` 图标与明确中文提示语；单侧完成同时显示 `✓` 与文字状态。
- **VoiceOver 支持**：`+` / `−` 按钮提供明确 `accessibilityLabel`（“增加次数” / “减少次数”）；进度轨道汇总为“第 1 轮，第 2 个动作，共 4 个动作”。

## 10. 仍使用模拟数据或尚未实现的功能清单

Codex 在接手开发原生 SwiftUI 版本时，需注意以下原型边界，切勿直接将占位数据当成真实业务能力：

1. **静态本地课程库与未确认的哑铃杆重**：
   - 当前 `WORKOUT_OPTIONS` 为前端硬编码示例课程；「周六 · 弹性训练安排」为示例日期标签。
   - 用户自有配重片（`1.25 / 1.5 / 2.0 / 2.5 kg × 4`）的理论组合已精确校验，但**塑料哑铃杆自重、锁扣重量及安全承重上限仍为未知/待确认状态**，需后续补充硬件实测值后再允许用户输入「单只整铃总重」。
2. **数据持久化与历史记录**：
   - 原型仅在内存 `useState` 中保存单次训练的 `loggedSets` 与 `skippedRecords`，刷新页面即清空；原生版需接入 `SwiftData` / `CoreData` 持久化每次训练实录、起止时间、跳过记录与 `SessionOutcome`。
3. **弹性排课与恢复推荐算法**：
   - 原型中「更换课程 / 顺延今日」仅作当次会话切换；长期的训练日历、基于近 7 天肌群疲劳度的弹性课表推荐尚未实现。
4. **真人示范视频资产**：
   - 目前无真实动作视频文件，需等真实视频素材导入 App Bundle 或本地缓存后，按动作 ID 绑定 `videoUrl`。
5. **后台锁屏保活与 Live Activities（灵动岛）**：
   - Web 原型仅演示前台计时与 Web Speech API；原生 iOS 需实现锁屏/后台计时校验（记录 `Date` 时间戳差值而非仅靠每秒累加）、以及组间休息倒计时 `ActivityKit` 灵动岛实时活动。
6. **原型调试面板**：
   - 网页右侧 `Phase1SpecPanel.tsx`、`LiquidGlassComparisonPanel.tsx`、`SchemeBSpecPanel.tsx` 与顶栏直达按钮（`[调试直达]`、`注入测试视频流`）**仅用于设计验收与原型验证，严禁带入原生 App 正式界面**。

## 12. 第一阶段三大核心主页面设计规范

### 12.1 训练总览（`TodayOverviewView`）
- **单一视觉焦点**：上方仅保留周数/标题与 3 个紧凑图标快捷入口，紧接大画幅「今日推荐」头图卡（高 `272pt`，SE `232pt`，圆角 `26pt`），底部暗角渐变之上仅放置标签、标题、预计耗时/轮次，以及一组主次按钮：

  - 次按钮：**`配重 / 明细`**（悬浮玻璃胶囊，高 `48pt`），进入 B1.5 配重选择、休息参数调整与 01–04 动作预览页。
- **信息分层与克制**：
  - 使用细分割线（`white @ 8%`）组织「本周弹性训练结构」4 段进度条、「最近一次训练」「弹性排程 · 下次建议」「身体趋势摘要（体重 / 腰围 + 极简折线）」。

### 12.2 弹性训练计划（`FlexiblePlanView`）
- **非固定日历哲学**：明确标注 `ADAPTIVE CYCLE · 无固定星期绑定`，不设「周二/四/六/日强制打卡」或连胜惩罚。
- **主观恢复状态**：提供 3 档纯主观体感分段开关（`状态充沛` / `正常负荷` / `略感疲惫`）。当用户选择「略感疲惫」时，推荐卡自动切换为「恢复优先建议（胸椎肩髋舒展）」，并用琥珀色（`#E3A05B`）温和提示“恢复是周期的正常部分，不计失败”。
- **实际排程调节**：周序列支持上移/下移未完成顺位（已完成顺位锁定）、替换任意课程（含改恢复日）与「主动推迟本顺位」，并将操作写入下方近期弹性调整记录。

### 12.3 训练历史（`WorkoutHistoryView`）
- **双视图与筛选**：右上支持「时间线 / 月历」切换，下方提供 `全部` / `力量` / `有氧` / `恢复` 胶囊筛选。
- **严格事实口径**：
  - 区分 **完整完成**（`#C8F542`）、**部分完成**（`#E3A05B`）与 **提前结束（0组）**（弱灰）。
  - **核心统计规则**：顶部「有效训练次数」与「累计有效时长」**绝不计入 0 组提前结束会话**，并保留 `complete / total` 的准确区分。
  - **数据来源标识**：列表与详情页明确区分 `[演示样本数据]` 与实时训练写入的 `[本次实录]`。
- **单次实录详情**：点入任意历史记录可查看起止时钟、暂停秒数、实录组数/总次数/有效时长、逐组动作名称（含左右侧标注）、实际配重（明确区分片重 + 未知杆）、实休秒数与主观难度（轻松/正好/吃力），以及跳过动作列表。

## 13. Liquid Glass 严格边界与 SwiftUI 原生映射

依据多轮对比验证（避免塑料渐变与首页过度玻璃化），**本系统仅在以下 3 类悬浮层使用 Liquid Glass**：
1. **底部 4-Tab 主导航栏**（`BottomGlassTabBar`，仅非训练浏览态显示）；
2. **总览大图次级胶囊按钮**（`配重 / 明细`，叠加于高反差运动摄影之上）；
3. **「训练进行中 (`active`)」4 组悬浮控件**：顶部 `退出` 胶囊、顶部 `音量` 圆钮、右侧一体式 `次数调节器` 胶囊、底部非主操作 `重播/静音` 与 `上一动作/暂停/跳过` 长条。

**绝对禁用规则**：
- **高对比主操作按钮**（`开始今日训练`、`完成本动作`、`设为今日训练并配置`）**必须保持纯实色 `#C8F542` + `#111315` 深字**，不得添加白边高光或渐变；
- 纯黑/深灰列表壁、首页分段选项卡（`力量A/B/有氧/恢复`）与数据明细行**禁止使用假毛玻璃**；
- 原型中的 `.lg-optical-pill`（`src/index.css`）仅为 Web CSS 光学降级模拟；iOS 原生工程应使用：
  - iOS 26+：`glassEffect(.regular.interactive(), in: .capsule)` 配合 `GlassEffectContainer`；
  - iOS 17/18：`.background(.ultraThinMaterial)` + `0.5pt` 顶部微弱高光描边，并自动尊重系统 `accessibilityReduceTransparency` 与 `accessibilityDarkerSystemColors`。
